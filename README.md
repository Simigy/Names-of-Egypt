# اسمك في مصر القديمة · Names of Egypt

أداة مجانية تعمل بالكامل داخل المتصفح تحوّل الاسم إلى **هيروغليفية + قبطية + إنجليزية + عربية**،
وترسم بطاقة جاهزة للتحميل أو الطباعة أو المشاركة، دون سيرفر ودون رفع أي بيانات.

A free, 100% client-side card generator: type a name, get hieroglyphs, Coptic, English and Arabic
on a canvas card you can download, print or share. No server, no account, no tracking.

- الموقع / Live demo: <https://simigy.github.io/Names-of-Egypt/>
- الملف الأساسي / Single file: `index.html`

---

## المزايا · Features

- تحويل تقريبي للاسم حرفاً بحرف إلى الهيروغليفية والقبطية، مع قاموس للأسماء الكنسية الشائعة.
- تصحيح يدوي لكل كلمة (عربي/إنجليزي) والنتيجة تتحدّث فوراً.
- أربع بطاقات عرض + خيارات: رأسي/أفقي، خرطوش، قراءة من اليسار، صيغ كنسية.
- خلفيات: بردي، ذهبي، فضي، لازوردي، أو صورة خاصة.
- صورة شخصية اختيارية بأربعة إطارات (مصري، حلقة هيروغليفية، قبطي).
- تصدير PNG / PNG شفاف / JPG / PDF، وحزمة ZIP بأربعة مقاسات.
- QR اختياري، علامة مائية اختيارية لنسخة المعاينة، واجهة عربية/إنجليزية، وإدخال صوتي.
- كل شيء يعمل على الجهاز: لا رفع، لا تخزين على سيرفر، ولا APIs مدفوعة.

## المقاسات · Sizes

من قائمة **المقاس**:

| الخيار | الناتج |
| --- | --- |
| تلقائي | حسب المحتوى |
| مربع 1080×1080 | بكسل، للسوشيال |
| ستوري 1080×1920 | بكسل |
| **بوست إنستجرام 1080×1350** | بكسل (4:5) |
| **خلفية موبايل 1440×3120** | بكسل (QHD) |
| **769×1280** | بكسل بالضبط (صورة عمودية/معاينة) |
| **1280×769** | بكسل بالضبط (معرض Fiverr الأفقي) |
| **A4 طباعة 2480×3508** | بكسل بالضبط = 300 DPI عند 21×29.7 سم |
| **مقاس مخصص** | تكتب العرض والارتفاع بالبكسل (200–4000) |
| بطاقة معايدة 13×18 سم / A5 / A4 | مليمتر (300 DPI) |
| كارت شخصي 9×5 سم | مليمتر |
| خرطوشة 5×10 / 10×5 سم | مليمتر |
| بطاقة مطوية A4 | مليمتر |
| بانر 3:1 | مليمتر |

- مقاسات البكسل تُحفظ في المتصفح (`cw` و`ch`)، وتُصدَّر بأبعادها بالضبط في PNG/JPG.
- أسفل قائمة المقاس سطر يوضح الأبعاد والميجابكسل والـDPI وأقصى مقاس طباعة للاختيار الحالي.
- عند اختيار مقاس بكسل صريح يتم تعطيل تصغير نسخة المعاينة، لكن العلامة المائية تبقى.
- **تنبيه:** العلامة المائية تخفّض مقاسات المليمتر (A4/A5/الكارت) إلى 900px عرض،
  فهي للمعاينة فقط. أطفئها قبل تصدير ملف الطباعة النهائي.
- في PDF يُشتق مقاس الصفحة من الأبعاد (وهذا سلوك قديم ومقصود للمقاسات المليمترية).

## الصور وموافقة الاستخدام · Photos & consent

قبل اختيار أي صورة يجب تفعيل مربع الموافقة:

> أوافق على استخدام هذه الصورة في بطاقتي. تُعالَج على جهازك فقط ولا تُرفع إلى أي سيرفر،
> وأقرّ بأن لي حق استخدامها أو أن معي إذن صاحبها.

- المربع **غير محفوظ** بين الزيارات، ولا بد من تفعيله في كل جلسة.
- إلغاء التفعيل يعطّل حقلي الصور ويمسح الصور المحمّلة فوراً.
- الصور تُقرأ عبر `File`/`ObjectURL` داخل الصفحة فقط، ولا يوجد أي طلب شبكة لها.

للعملاء (نص جاهز في متطلبات الطلب على Fiverr):

> من فضلك أرسل الصورة التي تريد استخدامها، وأكّد في الرسالة: «أملك حق استخدام هذه الصورة
> وأوافق على استخدامها في التصميم». وإن كنت تسمح بعرض التصميم في معرض أعمالي أضف:
> «أوافق أيضاً على عرض التصميم كعينة عمل». بدون هذا التأكيد لن أستخدم أي صورة شخصية.

## الخصوصية · Privacy

- لا حسابات، لا كوكيز تتبّع، لا تحليلات، لا سيرفر.
- الإعدادات فقط تُخزَّن في `localStorage` (مفتاح `noe`) ويمكن حذفها من زر «استعادة الإعدادات».
- الصور لا تُرفع. الإدخال الصوتي (اختياري) يعتمد على خدمة المتصفح نفسه وقد يرسل الصوت لخوادم المتصفح،
  وهذا موضّح داخل الصفحة، والتطبيق لا يخزّن أي صوت.

## الأسماء والمصادر · Names & sources

- التحويل **نقل صوتي تقريبي** وليس ترجمة رسمية؛ الأصوات المفخمة والحلقية لها أقرب مقابل فقط.
- الأسماء الكنسية والكتابية المعروفة (مثل مينا، ميخائيل، شنودة، موسى، متى، مارثا…) تأخذ صيغتها
  الشائعة من قاموس داخلي (46 مدخلاً، منها 19 اسماً كتابياً أُضيفت بعد مراجعة يدوية).
- الصيغ **اجتهاد لغوي** من مصادر متاحة، وليست مراجعة أو اعتماداً رسمياً من أي جهة كنسية،
  ولا يُدّعى أنها مطابقة تاريخياً بنسبة 100%.
- تظهر أسماء القاموس كاقتراحات تلقائية في حقل الاسم أثناء الكتابة (عربي فقط).

### عن كتابَي القواعد المرفقين

الكتابان:

1. *قواعد اللغة القبطية — أبونا أندرياس المقاري، الجزء الأول* — ISBN 977-241-162-2
2. *قواعد اللغة القبطية — أبونا أندرياس المقاري، الجزء الثاني* — ISBN 977-240-248-3

مرجعان **لقواعد اللغة** (تصريف أفعال/أسماء وتمارين)، وليسا قوائم أسماء. تم فحص فهارسهما
وصفحاتهما الأخيرة: لا يوجد فهرس أسماء أو مسرد أعلام، والصفحات صور ممسوحة بلا طبقة نصية،
لذلك لم تُستخرج أسماء آلياً منهما ولم تُنسخ محتوياتهما.

ما أُضيف فعلاً: راجع المالك أمثلة الأسماء الواردة في شرح الحروف والأصوات (ج1) وفي الأمثلة
والجمل (ج2) يدوياً، ثم أضفنا 19 مدخلاً كتابياً إلى القاموس (مثل: مارثا، يعقوب، موسى، هارون،
متى، لوقا، سليمان، أليصابات، هابيل، قايين، فيلبس، توما، سمعان، حنة، قيافا، بيلاطس، هيرودس).
تحقّقنا من الصيغ مقابل الأشكال الساحيدية الشائعة في قوائم الأسماء القبطية المنشورة، لا آلياً
من صور الكتابين. القائمة **عيّنة وليست فهرساً كاملاً** للأعلام، ولا يعضدها أي اعتماد كنسي.
يبقى الكتابان مذكورين كمرجع للتهجئة والقواعد، مع الاحتفاظ بحقوق ناشرهما (دار مجلة مرقس).

إن أردت توسيع قاموس الأسماء: أضف الاسم في المصفوفة `D` داخل `index.html` بالشكل
`['عربي','variants','ⲔⲞⲠⲦⲒⲔ','English']`، ويُفضَّل ذكر مصدر كل صيغة.

## صور المعرض · Listing images

`gallery/` فيه صور الإعلان (Fiverr) بمقاس **1280×769**:

- `cards/` — بطاقات أصلية صُدِّرت من التطبيق (769×1280، بدون علامة مائية).
- `fiverr-1.png` … `fiverr-3.png` — صور المعرض النهائية.
- `Names-of-Egypt-sample-cards.pdf` — نموذج من صفحتين (A4) لرفعه في جاليري Fiverr.
- `compose.py` / `sample_pdf.py` — سكربتات التوليد (Pillow، وتحتاج `arabic_reshaper` و`python-bidi` للنص العربي).

الصور دي للعرض فقط؛ أي بطاقة يستلمها العميل تُصدَّر من التطبيق نفسه بنفس المحرك.

## التشغيل والنشر · Run & deploy

```bash
# محلياً (لا يفتح file:// بشكل موثوق بسبب تحميل الخطوط/المكتبات)
python -m http.server 8765
# ثم افتح http://localhost:8765/
```

النشر: ارفع `index.html` إلى فرع `main` في مستودع GitHub، وفعّل **Settings → Pages → Deploy from branch → main / (root)**.
الموقع منشور حالياً على <https://simigy.github.io/Names-of-Egypt/>.
